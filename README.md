# StockProof — Blockchain-Based Financial Report Verification Platform

**Trust Every Financial Claim.**

StockProof is a full-stack MVP platform that independently verifies individual financial claims generated by AI Agents against authoritative financial statement datasets, produces a structured 15-section Evidence Report (Browser, PDF, JSON), supports Human-in-the-Loop (HITL) auditor overrides, and anchors cryptographic SHA-256 report and evidence hashes on **Avalanche Fuji Testnet**.

> **Immutability Scope**: Blockchain registration proves that a verification record and its associated evidence hash have not been altered after registration. It does **not** certify that raw source filings are inherently error-free.

---

## 1. Core Workflow

```text
Buyer Agent → Seller Agent → StockProof Verification Engine → Evidence Report → Blockchain Verification Record
```

1. **Upload & Extraction (`/upload`)**: Drag-and-drop PDF, Excel (`XLSX`/`XLS`), `CSV`, or `JSON` financial reports. Files are hashed off-chain (`SHA-256`), parsed (`pdfjs-dist` / `xlsx`), and mapped into structured claims via server-side Gemini AI (`@google/genai`) or deterministic structured column mapping.
2. **Deterministic Verification Engine (`src/lib/verification.ts`)**: Independently validates every claim across 8 rules (Numerical Tolerance, Reporting Period, Unit Normalization `VND` / `Million VND` / `Billion VND`, Report Type `Consolidated` vs `Separate`, Formula Recalculation, Source/Evidence Presence, and Human Review triggers).
3. **Human-in-the-Loop Audit (`/verification`)**: Auditors inspect split Seller vs. Reference comparisons, review rule checks, override or correct values with mandatory comments, and record `HUMAN_APPROVED` audit trail decisions.
4. **Evidence Explorer (`/evidence`)**: Generates the complete 15-section Evidence Report with downloadable binary PDF (`pdfkit`) and JSON export.
5. **Blockchain Registry (`/blockchain`)**: Anchors document and evidence SHA-256 hashes via `contracts/StockProofRegistry.sol` on **Avalanche Fuji Testnet (`Chain ID 43113`)** using `ethers` wallet signing (`LIVE_FUJI_WALLET`) or clearly labeled `DEMO_SIMULATION` mode.

## 2. Demo Scenario (`DEMO DATA`)

Initial seeded dataset: **FPT Corporation (DEMO DATA)** (`HOSE: FPT`, `FY2025`, Consolidated), 10 claims demonstrating:
- **5 VERIFIED** (including unit normalization from `7,857,000 Million VND` → `7,857 Billion VND`)
- **2 MISMATCH** (wrong reporting period `Q3/2025` for Total Equity, and formula discrepancy `18.5%` vs `12.3%` Revenue Growth)
- **1 INSUFFICIENT EVIDENCE** (Total Liabilities missing source document/page citation)
- **2 NEEDS HUMAN REVIEW** (Operating Profit footnote ambiguity and Operating Cash Flow conflicting draft memo)

## 3. Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide React, Ethers.js v6
- **Backend**: Express (`server.ts`), Vite middleware, Multer, `pdfjs-dist`, `xlsx`, `pdfkit`, `@google/genai`
- **Database**: PostgreSQL (Cloud SQL + Drizzle ORM in `src/db/`) with local JSON fallback (`data/stockproof-demo.json`) for zero-config Demo Mode
- **Authentication**: Firebase Authentication (Google Sign-In)
- **Smart Contract**: Solidity (`contracts/StockProofRegistry.sol`) targeting Avalanche Fuji Testnet (`Chain ID 43113`)

## 4. API Endpoints (`server.ts`)

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/api/health` | Health check |
| `POST` | `/api/auth/session` | Sync Firebase user session with PostgreSQL |
| `GET` | `/api/workspace` | Load active reports, reference dataset, activities, and Fuji status |
| `GET` | `/api/sample-report` | Download sample `CSV` or `JSON` financial claims file (`?format=csv\|json`) |
| `POST` | `/api/reports/upload` | Upload PDF/XLSX/CSV/JSON, hash SHA-256, extract & verify claims |
| `POST` | `/api/reports/:reportId/claims` | Update extracted claims and re-run deterministic verification |
| `POST` | `/api/reports/:reportId/claims/:claimId/review` | Record HITL auditor decision (`VERIFIED`, `MISMATCH`, `INSUFFICIENT EVIDENCE`) |
| `GET` | `/api/reports/:reportId/evidence.pdf` | Generate and download binary PDF Evidence Report |
| `POST` | `/api/reports/:reportId/blockchain` | Save Avalanche Fuji wallet tx (`LIVE_FUJI_WALLET`) or `DEMO_SIMULATION` |
| `POST` | `/api/settings/tolerance` | Update numerical rounding tolerance (`%`) and re-verify reports |
| `POST` | `/api/reset` | Restore initial FPT `DEMO DATA` workspace |
| `GET` | `/api/fuji-status` | Query Avalanche Fuji Testnet RPC block height |
| `GET` | `/api/contract-source` | Return `contracts/StockProofRegistry.sol` source |

## 5. Local Development & Testing

```bash
# 1. Install dependencies
npm install

# 2. Configure environment variables (optional for Demo Mode; required for AI PDF extraction & Cloud SQL)
cp .env.example .env

# 3. Run unit tests (deterministic engine & document processor)
npx --yes tsx --test src/lib/verification.test.ts

# 4. Start full-stack dev server on http://localhost:3000
npm run dev

# 5. Typecheck & production build
npm run lint
npm run build
npm start
```
